# AURA training pipeline, Python 3.11.

# Everything below is pinned to a lower bound rather than an exact version: the
# pipeline is run in Colab as often as it is run locally, and Colab's preinstalled
# numpy/pandas move faster than any pin would survive.

# Core numerics. The pipeline runs on these alone.

# Supabase. The SDK is preferred; supabase_io falls back to REST over requests.
supabase>=2.4
